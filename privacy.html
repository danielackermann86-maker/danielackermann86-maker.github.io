Privacy Policy

Raspi Backup App is a personal, non-commercial application used exclusively by its owner.

Google Drive Access

The application uses Google OAuth 2.0 to access the owner's Google Drive account for storing and managing encrypted Raspberry Pi backups.

Data Processing

Backup data is encrypted locally using restic before being transferred to Google Drive via rclone.

No data is sold or shared with third parties. The application does not operate a separate user database or analytics service.

Access Revocation

The owner can revoke access at any time through their Google Account security settings.
